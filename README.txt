EASY WAY TO PUBLISH FROM ANDROID (GitHub Pages, free):
1. Open https://github.com in Chrome and create/sign into a free account.
2. Tap +, then New repository.
3. Name it lakhi-birthday (or another name), choose Public, and create the repository.
4. Open the repository, choose Add file -> Create new file.
5. Name the file exactly: index.html
6. Open the index.html file included in this folder in a text editor, copy all its contents, paste into GitHub's editor, and commit the file.
   Alternative: repository -> Add file -> Upload files, then upload index.html from your phone's Files app.
7. Open repository Settings -> Pages.
8. Under Build and deployment, choose Deploy from a branch; branch main and folder /(root); Save.
9. Wait a minute or two. The Pages section will show your public website URL, usually:
   https://YOUR-USERNAME.github.io/lakhi-birthday/
10. Open that link on your phone and send it to Lakhi.

NOTES:
- No paid domain or hosting is required.
- GitHub's menus can look a little different on mobile. If needed, use Chrome menu -> Desktop site.
- Birthday date is set to October 20, 2026, using the visitor's local timezone.
- Photos chosen in the gallery and music selected from a phone are local previews; they are not shared with other visitors. For photos/music to be available to everyone, add permitted image/audio files to the repository and update the HTML before publishing.
- The page does not autoplay music; the visitor must choose an audio file and tap Play.
